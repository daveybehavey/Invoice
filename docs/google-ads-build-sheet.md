# Google Ads Build Sheet

Use this as the exact setup for the first cheap search test. The goal is not volume. The goal is to find whether NoteBill can earn clicks and conversions from high-intent searchers.

## Campaign

- Campaign name: `NB | Search | High Intent | US`
- Goal: `Sales`
- Campaign type: `Search`
- Networks: `Google Search only`
- Search partners: `Off` for the first test
- Display expansion: `Off`
- Locations: `United States`
- Language: `English`
- Ad schedule: `All day` for the first 7 to 10 days
- Bidding: `Maximize clicks` with a CPC cap, or `Manual CPC` if you want the tightest control
- Daily budget: `$10 to $20`
- Final URL expansion: `Off`
- Conversion goal: `pro_unlock_verified`

If budget is especially tight, start with the mobile-first variant:

- keep the `NB | Mobile` ad group live
- point it at `/invoice-app-on-phone`
- pause the contractor, service-business, and statements ad groups until the mobile test proves demand
- keep the first test focused on the exact intent that is most likely to convert from a small budget

## Best-practice notes

- Keep exact and phrase match only at first.
- Do not add broad match until you have enough conversion data and clean search terms.
- Review search terms after the first few days and add negatives aggressively.
- Optimize to the actual paid conversion: `pro_unlock_verified`.
- Do not send traffic to the launcher root if the keyword intent is specific; use the matching SEO page.
- Keep the first test small so you can see whether the offer and landing page convert before scaling spend.
