# NoteBill Support

Last updated: 2026-04-13

This page provides public support contact details for NoteBill.

## Contact Details

- Support email: `support@notebill.app`
- Contact email: `contact@notebill.app`
- Info email: `info@notebill.app`
- Direct contact: `david@notebill.app`
- Developer: David Heslop

## What Support Can Help With

You can use the addresses above for help with:

- Sign-in or account access issues
- Invoice import, OCR, or transcription questions
- Saved drafts, export, or send issues
- Billing, subscriptions, or payment-link questions
- Privacy or data deletion requests

## What To Include In Your Message

To help resolve your request quickly, include:

- The email address associated with your NoteBill account, if applicable
- A short description of the issue or request
- The device model and Android version if the issue is mobile-specific
- Screenshots or the invoice ID if the request relates to a saved draft or invoice flow

## Data Deletion Requests

If you want account-related data deleted, send your request to `support@notebill.app`.

For the quickest review, use a subject line like `Delete my NoteBill data` and include the account email address you want reviewed.
