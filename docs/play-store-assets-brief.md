# NoteBill Play Store Assets Brief

## Goal

Make the Play Store listing feel clear, mobile-first, and trustworthy to service operators who just want to invoice faster.

The listing should reinforce the same simple promise the app now uses:

- start from rough job notes
- approve the money decisions
- send a clean invoice faster
- make repeat work and follow-up easier

## What the screenshots should prove

1. This is not a generic accounting dashboard.
2. The app is easy to understand on a phone.
3. The workflow starts from messy real-world input.
4. Money decisions stay visible.
5. Repeat work and follow-up are part of the value, not an afterthought.

## Screenshot order

1. Launcher hero
2. Billie intake with real-looking notes
3. Review state with visible money decisions
4. Manual editor with send-ready handoff
5. Library with needs-attention / follow-up cues
6. Client workspace with repeat-work context
7. Optional extra: scratchpad or import flow

## Recommended screenshot captions

1. Start from rough job notes instead of a blank invoice
2. Let Billie turn messy details into a clean draft
3. Approve the money decisions before anything gets sent
4. Finish the invoice with a cleaner send and payment handoff
5. See what needs follow-up without digging through old invoices
6. Make repeat client work faster with saved memory and next steps
7. Capture notes during the day and invoice later

## Feature graphic message

### Primary line

`Turn rough job notes into client-ready invoices.`

### Secondary line options

- `Approve the money. Send faster.`
- `Built for repeat work and easier follow-up.`
- `Mobile-first invoicing for service work.`

## Visual direction

- warm, premium, practical
- real mobile UI, not a fake marketing dashboard
- show progression, not random screens
- keep text overlays short and high-contrast
- avoid trying to explain every feature in one asset

## Avoid

- too much "AI" language on assets
- cluttered screenshots with tiny unreadable copy
- enterprise-looking dashboards
- generic bookkeeping language
- claims about accounting or tax compliance

## Final review rule

If a tradesperson or solo operator looks at the listing for five seconds, they should immediately understand:

"This helps me go from messy notes to a clean invoice faster on my phone."
