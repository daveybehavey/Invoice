# Post-launch polish tasks

## Triggered by friction buckets
- **Activation**: clarify the homepage hero CTA (stronger start with Billie), reduce copy noise around "New intake" cards, highlight primary path with calm surfaces.
- **Trust**: call out totals/taxes in review row, add subtle copy for unpaid vs paid states in the library, keep confirmation language consistent.
- **Billie**: surface Billie status chips in intake/editor/library, reinforce that Billie suggests decisions (banner and chips), keep assistant styling calm (shared tokens, quiet highlights) while not introducing new flows.
- **Payment**: polish unpaid/paid callouts (chip + row), make payment-link button more prominent in library/manual, emphasize that generating payment links is a deliberate step, reinforce reminder states.

## Tactical actions
1. Reduce hero copy from long paragraphs to a succinct headline + one-sentence support plus `Get started` CTA that triggers the Billie intake path.
2. Audit launcher, intake, manual, and library surfaces for competing card borders/shadows; align with shared surface tokens; ensure there's only one dominant action per screen.
3. Update library invoice card template (amount/title/status) to use accent color for totals, muted text for metadata, and a consistent CTA area.
4. Add or strengthen assistant status chip text (e.g., "Billie is ready to refine") near the billie workspace and decision panels.
5. Ensure unpaid/paid states use the same chip/alert pattern across library/manual/preview to avoid confusion.
