# iOS Screenshot Capture Checklist

Goal: prepare App Store screenshots from the current mobile product without needing a personal Mac yet.

Apple lets you upload 1 to 10 screenshots per localization in App Store Connect, and the web tools are enough to prep the store record before you have a Mac-based build path.

## What to capture first

Capture from a phone-sized browser view of the current live web app.

Prioritize these screens:

1. Quick AI invoice entry
2. Rough notes to draft state
3. Money review / approval state
4. Send-ready invoice or PDF handoff
5. Client statement and follow-up flow
6. Repeat-work / invoice library memory screen
7. Trust / FAQ screen

## Recommended story order

Use the screenshots to tell one simple story:

1. Paste rough notes
2. Billie drafts fast
3. You approve the money
4. Send the invoice
5. Follow up and manage statements
6. Reuse the work next time

## Suggested capture checklist

Before taking screenshots:

1. Use the current mobile responsive build
2. Make sure the quick AI invoice path is visible
3. Make sure the pricing choice is not the first thing blocking the flow
4. Make sure the trust / FAQ block exists on the landing pages
5. Avoid showing cluttered or developer-looking states

## Captions to pair with the images

1. Paste rough notes and start fast
2. Billie prepares the first draft
3. You stay in control of the money
4. Send a clean invoice or PDF handoff
5. Keep statements and follow-up organized
6. Reuse repeat work faster next time
7. See why this is more than a generic AI invoice tool

## Recommended assets to prep alongside screenshots

1. App icon set
2. App name
3. Subtitle
4. Description
5. Keywords
6. Support URL
7. Privacy policy URL
8. Age rating answers
9. Advertising ID and data use answers

## What not to do

1. Do not lead with a generic dashboard screenshot
2. Do not lead with a crowded settings screen
3. Do not use screenshots that require too much explanation
4. Do not make the first screenshot about pricing

## Best-practice note

The first screenshot should communicate the product wedge immediately:

- rough notes in
- Billie drafts fast
- you approve the money
